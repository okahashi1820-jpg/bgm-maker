# BGMメーカー

タップで作れるゲーム用BGM作曲ツール（スマホ向け・オフライン対応のWebアプリ）。

- 公開URL: https://okahashi1820-jpg.github.io/bgm-maker/
- Chromeで開き、メニューの「ホーム画面に追加」（または画面上の「📲 アプリとして追加」）でアプリとして使えます。
- 作った曲はその端末のブラウザ内にだけ保存されます。

## 更新するとき
`index.html` を変えたら、`sw.js` の `VERSION` と `index.html` の `APP_VERSION` を同じ値で上げる（例: v1.0 → v1.1）。
上げないと、インストール済みの端末には古い版が表示され続けます。
